## 🌿 简体中文

### 软件介绍

**宿芽（Suya）** 是一款专为小型民宿、家庭旅馆及个人住宿经营者设计的 Windows 桌面管理工具。

软件以轻量化、操作便捷和直观记录为设计理念，将日常入住、续房、退房、收支管理以及经营统计集中在一个简洁的界面中。

### ✨ 主要功能

**🏠 房间管理**
- 查看房间当前状态：空房 / 已入住。
- 快速选择房间并完成日常登记。
- 查看各房间的入住及费用记录。

**📝 快捷入住与续房**
- 快速登记住宿收入。
- 支持续房操作及零元金额记录。
- 根据实际住宿日期记录续住情况。
- 支持一次性收款和按住宿日期分摊收入两种统计口径，避免重复计算。

**💰 收支与成本管理**
- 记录房费收入及日常经营支出。
- 续房时可按实际续住日期自动计算一次性用品成本，默认每次 8 元。
- 完整入住结束并确认退房时，自动记录一次打扫费用，默认 40 元，避免重复扣费。
- 支持手动添加洗衣液等额外用品支出。
- 支持修改默认成本参数。

**📊 经营统计**
- 查看每日收入及相关经营数据。
- 提供周期性统计与每周经营报告。
- 区分实际收款与住宿日期分摊口径，使经营数据更加清晰。

**🔔 桌面提醒**
- 支持 Windows 桌面定时通知。
- 可自定义提醒时间。
- 支持每周经营报告提醒。

**🌱 轻量化交互**
- 简洁的房态管理界面。
- 快捷操作入口。
- 可爱的「宿芽」角色视觉设计。
- 适合 Windows 桌面日常使用。

### 📥 下载与安装

1. 打开 GitHub 仓库的 **Releases** 页面。
2. 下载最新版本的 Windows 安装程序（`.exe`）。
3. 运行安装程序，根据提示完成安装。
4. 启动「宿芽」，开始管理民宿经营记录。

> 本仓库用于发布软件安装包、更新日志及使用说明，不提供完整源代码。

### 📌 注意事项

- 请定期备份重要经营数据。
- 软件记录仅供日常经营管理参考。
- 实际税务及财务申报应以当地法律法规和正式凭证为准。
- 部分功能可能随软件版本更新而调整。

## 🌍 English

### About Suya

**Suya Homestay** is a lightweight and charming Windows desktop application designed for small homestays, guesthouses, and independent accommodation operators.

It simplifies everyday property management by combining guest check-ins, stay extensions, room status tracking, income and expense records, and business statistics into one intuitive interface.

### ✨ Key Features

**🏠 Room Management**
- Track room availability: Vacant / Occupied.
- Quickly select rooms and register daily operations.
- Review room-specific stay and expense records.

**📝 Check-in & Stay Extensions**
- Quickly record accommodation payments.
- Support stay extensions and zero-value transactions.
- Track extensions according to the actual stay dates.
- Support both payment-based and stay-date-based income reporting to prevent double counting.

**💰 Income & Expense Tracking**
- Record accommodation revenue and operating expenses.
- Automatically record configurable amenity costs for stay extensions, with a default of ¥8 per applicable day.
- Apply a configurable cleaning fee once per completed stay at confirmed checkout, with a default of ¥40.
- Add miscellaneous expenses such as laundry detergent and other supplies.
- Customize default expense settings.

**📊 Business Statistics**
- View daily revenue and operating records.
- Access periodic statistics and weekly summaries.
- Distinguish actual payments from revenue allocated by stay date.

**🔔 Desktop Notifications**
- Receive scheduled Windows desktop reminders.
- Customize notification times.
- Get weekly business report notifications.

**🌱 Simple & Friendly Design**
- Minimal, easy-to-use interface.
- Convenient access to frequent operations.
- An adorable mascot-inspired visual identity.
- Designed for everyday Windows desktop use.

### 📥 Download & Installation

1. Visit the repository's **Releases** page.
2. Download the latest Windows installer (`.exe`).
3. Run the installer and follow the instructions.
4. Launch Suya and start managing your homestay.

> This repository distributes application installers, release notes, and documentation. The complete source code is not publicly available.

### 📌 Notes

- Back up important business records regularly.
- Financial reports are intended for operational reference.
- Tax and accounting obligations should follow applicable local laws.
- Features may change between software releases.

## 🌸 日本語

### ソフトウェアについて

**宿芽（スヤ）・民泊かんたん会計** は、小規模な民泊施設、ゲストハウス、個人の宿泊施設運営者向けに開発された、軽量でかわいい Windows デスクトップ管理ツールです。

チェックイン登録、延泊管理、客室状況の確認、収支記録、経営データの集計など、日々の宿泊施設運営に必要な機能をシンプルな画面にまとめています。

### ✨ 主な機能

**🏠 客室管理**
- 客室の状態を「空室 / 入室中」で確認。
- 客室を選択してすばやく登録。
- 客室ごとの宿泊・経費記録を確認。

**📝 チェックイン・延泊管理**
- 宿泊料金を簡単に登録。
- 延泊処理および金額 0 円の記録に対応。
- 実際の宿泊日付に基づいて延泊を管理。
- 入金日基準と宿泊日基準の両方で収益を集計し、二重計上を防止。

**💰 収支・経費管理**
- 宿泊収入と運営経費を記録。
- 延泊時の日用品費を自動記録。初期設定は対象日ごとに 8 元（変更可能）。
- チェックアウト確定時に、1 回の宿泊につき清掃費を一度だけ計上。初期設定は 40 元（変更可能）。
- 洗濯洗剤などの追加備品費を手動で登録。
- 各種経費の初期設定を変更可能。

**📊 経営データの集計**
- 日別売上や運営状況を確認。
- 期間別集計と週次レポートに対応。
- 実際の入金額と宿泊日ごとの収益配分を区別して表示。

**🔔 デスクトップ通知**
- Windows の定時通知に対応。
- 通知時刻を自由に設定。
- 週次経営レポートを通知。

**🌱 シンプルで親しみやすいデザイン**
- 直感的で使いやすい画面。
- よく使う操作にすばやくアクセス。
- かわいいマスコットキャラクターを採用。
- Windows での日常的な利用に最適。

### 📥 ダウンロード・インストール

1. GitHub リポジトリの **Releases** ページを開きます。
2. 最新版の Windows インストーラー（`.exe`）をダウンロードします。
3. インストーラーを実行し、画面の案内に従ってインストールします。
4. 「宿芽」を起動して、民泊管理を始めましょう。

> 本リポジトリでは、インストーラー、更新履歴、利用案内を公開しています。ソースコード全体は公開していません。

### 📌 ご利用上の注意

- 重要な経営データは定期的にバックアップしてください。
- 集計結果は日常の運営管理を目的としています。
- 税務申告や正式な会計処理については、各地域の法令に従ってください。
- ソフトウェアのバージョンによって機能が変更される場合があります。
